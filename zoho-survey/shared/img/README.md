# shared/img

Static image assets used across all survey dashboard instances. All images are institutional branding assets for Universidad de Lima.

## Architecture Role

Presentation layer assets. Consumed by `loader.css` (splash screen, topbar) and `index.html` templates (footer, favicon). No dynamic or user-generated images.

## Key Files

| File | Usage | Dimensions | Consumer |
|------|-------|-----------|----------|
| `logo-horizontal.png` | Topbar logo in period navigator | ~200×40px | `loader.css` (`.topbar-logo`) |
| `logo-vertical.png` | Splash screen logo | ~150×200px | `loader.css` (`.logo-vertical`) |
| `logo-isotipo.png` | Footer logo in dashboard | ~30×30px | `template/index.html` footer |
| `favicon.png` | Browser tab icon | 32×32px | All `index.html` files |

## Dependencies

- **Consumer**: `loader.css` references images via relative paths from `shared/css/` to `shared/img/`
- **Consumer**: `template/index.html` references `logo-isotipo.png` and `favicon.png`
- **Source**: Institutional brand assets — not generated by any build process

## Configuration

No configuration needed. Image paths are hardcoded in CSS and HTML:
- CSS: `url('../img/logo-horizontal.png')` (relative from `css/` to `img/`)
- HTML: `<link rel="icon" href="../../../shared/img/favicon.png">`

## Technical Debt

- **Institutional coupling**: All images are ULIMA-specific. Reusing this system for other institutions requires replacing all four files.
- **No responsive images**: Single resolution for each asset. No `srcset` or `picture` element for different screen densities.
- **No SVG option**: Using PNG instead of SVG limits scalability and adds unnecessary bytes. SVGs would also support theming via CSS `fill`.

## AI Agent Notes

- Path resolution from period HTML: `../../../shared/img/{filename}` (3 levels up from `undergraduate/{period}/`).
- Path resolution from CSS: `../img/{filename}` (1 level up from `shared/css/`).
- To replace branding: replace all four PNG files with same filenames and approximate dimensions.
- Favicon: must be `.png` format; browsers handle it but `.ico` is more widely supported.
