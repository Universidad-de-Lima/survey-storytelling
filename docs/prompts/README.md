# Prompts

Archivos de prompts para agentes de IA contextualizados en el proyecto.

## Purpose

Proveer instrucciones y contexto reutilizable para GitHub Copilot, Cline, Cursor, Codex y otros agentes de IA que trabajen en este repositorio.

## Usage

Los prompts están diseñados para ser usados como:

1. **Instrucciones de sistema** en VS Code Agents (.instructions.md)
2. **Contexto inicial** para GitHub Copilot Chat
3. **Base de conocimiento** para code reviews automatizados
4. **Guías de refactorización** para agentes de IA
